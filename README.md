# Disco Elysium — редактор диалогов

Веб-редактор, который накладывает на любую фотографию диалог в стиле Disco Elysium (русская локализация): реплики навыков с проверками, варианты ответа, кнопка «Продолжить», портрет.

**Открыть:** https://backstab1.github.io/disco-elysium-dialog-editor/

- Перетащите фото, вставьте через Ctrl+V или нажмите на поле загрузки.
- Текст правится прямо на картинке или в панели слева.
- «Скачать PNG» сохраняет кадр в разрешении исходного фото.

Всё работает в браузере, фото никуда не загружаются.
